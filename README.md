Repositório destinado a resolver exercícios de lógica de programação utilizando JavaScript, com o objetivo de praticar funções e testar o raciocínio lógico. Este projeto faz parte da formação em Desenvolvimento Web da Trybe.

## ✨ Demonstração

> Este projeto é composto por funções que resolvem problemas de lógica, sendo validadas através de testes automatizados utilizando Jest.

## 💡 Sobre

Este projeto é composto por uma série de exercícios que envolvem a criação de funções em JavaScript para resolver problemas de lógica, como encontrar o maior número em um array, verificar palíndromos, calcular a soma de uma lista de números, entre outros. As funções são testadas automaticamente com a biblioteca **Jest**, garantindo que o comportamento esperado seja mantido.

## 🛠️ Habilidades desenvolvidas

- Manipulação de arrays, strings e números em JavaScript
- Escrita de funções puras com responsabilidade única
- Prática de testes automatizados utilizando Jest
- Aplicação de lógica de programação funcional

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
- Node.js
- Jest

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/exercise-functions.git
```

2. Acesse a pasta do projeto
```bash
cd exercise-functions
```
3. Instale as dependências
```bash
npm install
```
